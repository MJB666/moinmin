# 莫印泯 · 一键直达

三个「一键直达」小工具，都是纯前端 / 免安装的：把常逛的官方 App、商品页、商铺页面做成卡片，
点一下直接跳过去，省掉"打开 App → 搜索 → 翻到那个店"的步骤。

| 文件夹 | 是什么 | 怎么跑起来 |
|---|---|---|
| [`手机版导航站/`](手机版导航站/) | 手机优先的网页 App。液态玻璃、长按 2 秒 = 右键、背景图每分钟自动换、可播视频背景，支持「添加到主屏幕」当 App 用 | 双击 `一键开服.cmd`，手机连同一 WiFi 打开；或直接装 `莫印泯-轻量版.apk` |
| [`电脑端-莫印泯/`](电脑端-莫印泯/) | Windows 桌面小窗程序，单个 `.exe` 免安装。玻璃反光卡片、可拖动悬浮球、开售倒计时（到点弹窗响铃 + 窗口置顶） | 双击 `莫印泯.exe` |
| [`网页资源站/`](网页资源站/) | 带后台管理的纯静态资源导航站。数据存在浏览器 localStorage，也可以把图片传到阿里云 OSS | 双击 `serve.ps1`，开 `http://localhost:8899/` |

每个文件夹里都有自己的 `README.md`，细节看各自的。

## 手机版导航站

```
手机版导航站/
├─ index.html            程序入口
├─ style.css             液态玻璃样式
├─ app.js                全部逻辑
├─ media.js              素材清单（图片 / 视频列表）
├─ manifest.json         PWA 配置（「添加到主屏幕」用）
├─ sw.js                 离线缓存
├─ 一键开服.cmd           ★ 双击它，手机就能访问
├─ 服务.ps1              上面那个 .cmd 调用的服务脚本
├─ 重新生成素材清单.cmd    往素材文件夹里加了新东西后跑一下
├─ 安装说明.md            给完全不懂技术的人看的步骤
├─ 莫印泯-轻量版.apk      安卓安装包（约 4 MB，4 张内置图，无视频）
├─ 图片\  (4 张)
└─ 视频\  (空，需要自己放，见下面的说明)
```

### 三种用法

1. **电脑开服务**（最推荐）：双击 `一键开服.cmd` → 黑窗口里有一行 `http://192.168.x.x:8898/` →
   手机连同一个 WiFi，浏览器打开这个地址 → 浏览器菜单 → **添加到主屏幕**。
   这样数据能存下来（localStorage），用起来跟 App 一样。
2. **拷进手机**：整个文件夹拷到手机存储，用浏览器打开 `index.html`。
   缺点：部分浏览器不允许本地文件存数据，加进去的入口可能重启就没了。
3. **装 apk**：装 `莫印泯-轻量版.apk`，程序 + 4 张图打包在里面，不用电脑开着、不用联网、数据不会丢。

### 操作

桌面上是一排按钮，**长按 2 秒 = 右键**（手指上会转一个进度圈，转满才弹菜单，所以不会误触）：

| 按钮 | 点一下 | 长按 2 秒 |
|---|---|---|
| ＋ 添加 | 打开编辑面板加卡片 | — |
| 📋 剪贴板 | 把剪贴板里的链接存成卡片 | — |
| 🔁 自动切换 | 开 / 关背景图自动切换 | 立刻换下一张 / 选图 / 改间隔 |
| 🖼 选图 | 挑一张背景图 | 再选一张 / 回到内置图 / 图片列表 |
| ▶ 视频 | 开 / 关视频背景 | 选择视频 / 不用视频 |
| ☰ | 设置面板 | — |

卡片：**轻点**打开链接（App 协议如 `taobao://` 会先试着唤起 App，没装就跳备用链接）；
**长按**弹右键菜单（打开 / 复制链接 / 编辑 / 移到最前 / 删除）。

设置里可以调：自动切换间隔（10~300 秒）、**长按判定时长**（0.5~3 秒，默认 2 秒）、
省电模式（关掉毛玻璃，老手机更流畅）、卡片是否也用液态玻璃、导出/导入入口。

### 换成自己的素材

把图片丢进 `图片\`，视频丢进 `视频\`，双击 `重新生成素材清单.cmd`，刷新页面就出现在列表里了。
**文件名建议用英文或数字**，别带 `#` `[` `]`。开头的数字会被去掉当标题（`5-我的背景.mp4` → 标题「我的背景」）。

## 电脑端-莫印泯

Windows 桌面小程序，**单个 exe，双击运行，不需要装任何运行环境**。

- 视频背景（也可以只用图片背景，图片每 1 分钟自动换一张）
- 玻璃反光卡片，图标是带高光的玻璃球质感
- 软件名和图标居中显示在窗口正上方
- 📋 **存剪贴板链接**：在浏览器里复制商铺网址，点一下就存成卡片
- 🔮 **悬浮球**：开启后变成可拖动的小球浮在桌面，点一下弹卡片列表，不用切回主界面
- 内置**开售倒计时**，到点弹窗 + 响铃 + 窗口置顶，还给你一个「立即前往」按钮
- 卡片自由添加 / 编辑 / 删除

```
电脑端-莫印泯/
├─ 莫印泯.exe           ★ 双击运行
├─ 莫印泯.cs            全部源码（UI 也是代码画的，没有 XAML）
├─ build.ps1            编译脚本
├─ 一键构建.cmd          ★ 双击它重新编译 / 换图标
├─ app.manifest         高 DPI 声明
├─ app.ico              程序图标
├─ icon.jpg             界面里显示的圆形图标
├─ preview.jpg / preview - 副本.jpg / 1.gif    界面素材
└─ README.md            详细说明
```

**换图标**：把你的图存成本文件夹里的 `icon.png`（名字带 `icon` 也会被认出来），双击 `一键构建.cmd`，
它会自动转出多尺寸 `.ico` 并重新编译。
⚠️ 别直接双击 `build.ps1` —— Windows 默认用记事本打开 `.ps1`，你会看到一堆代码但什么都没发生。

**换背景视频**：把视频放进本文件夹命名 `bg.mp4`（或 `后台.mp4` / `背景.mp4`，也会自动认一个视频文件）。

> 仓库里**没有放视频**（体积 + 版权原因），所以克隆下来后背景是自带的动态渐变光晕。
> 想让它变成视频背景，自己放个 `bg.mp4` 进去就行。

数据存在 `%APPDATA%\莫印泯\`（`links.json` 卡片、`settings.json` 设置）。

## 网页资源站

带后台的纯静态资源导航站：`index.html` 前台 + `admin.html` 后台，数据存在 localStorage，
不依赖任何后端、不需要数据库。

```
网页资源站/
├─ index.html           前台
├─ admin.html           后台（默认密码 admin123）
├─ serve.ps1            ★ 双击它起服务
├─ assets/
│   ├─ style.css        样式
│   ├─ seed.js          默认数据
│   ├─ store.js         读写 localStorage
│   ├─ app.js           前台逻辑
│   └─ admin.js         后台逻辑
├─ upload-oss.ps1       把图片批量传到阿里云 OSS（可选）
├─ oss.conf.example.json  OSS 配置模板（复制成 oss.conf.json 再填）
└─ README.md            详细说明
```

- 前台 `http://localhost:8899/`，后台 `http://localhost:8899/admin.html`
- 端口被占用：`.\serve.ps1 -Port 8900`
- 后台登录密码默认 `admin123`，在「网站设置」里改

> ⚠️ 后台密码是**纯前端校验**的，只适合本机 / 内网自己用，**不能当作真正的安全防护**。
> 想部署到公网，得先自己加一层服务端鉴权。

`oss.conf.json` 里放的是阿里云 AccessKey，已经写进 `.gitignore`，**不会**进仓库。
仓库里只有 `oss.conf.example.json` 占位模板。

## 技术上有意思的几处

- **「液态玻璃」不是简单的 `backdrop-filter: blur`**：
  SVG `feTurbulence` 生成有机噪声 → `feDisplacementMap` 把高光边框"掰弯"做出边缘折射 →
  再把图层拆成红 / 绿 / 蓝三个通道，用不同强度分别位移，最后 `feBlend screen` 叠回去，
  得到边缘的彩色色差（chromatic aberration）。每个面板的高光还会缓慢流动。
- **手机端长按当右键**：按下时画一个 SVG 进度圈，满了才触发，松手就取消，避免误触。
- **桌面端编辑窗口拖拽**：整个外框挂了 `DragMove()` 会让里面的按钮点不动，
  所以用 `Ui.HitInteractive()` 遍历视觉树判断命中目标是不是可交互控件，只有点在空白处才拖窗口，
  外层再套 `BitmapCache` 减少重绘。
- **apk 里视频能拖进度条**：所有资源和视频以 **STORED（不压缩）** 塞进 apk，
  这样 `AssetManager.openFd()` 能拿到真正的文件偏移量，`<video>` 发 Range 请求时可以直接从
  apk 里 seek，而不是把 440 MB 读进内存。（.NET 的 `CompressionLevel.NoCompression` 其实还是会写出
  deflate 流，得自己按 STORED 写 zip。）
- **apk 不用 Gradle**：aapt2 compile → aapt2 link → javac → d8 → 自写的 Java 打包器 → zipalign → apksigner。
