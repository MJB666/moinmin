# 莫印泯 · 一键直达官方 App / 商品页

一个 Windows 桌面小程序（单个 `.exe`，双击运行，**不需要装任何运行环境**）。

- **视频背景**：把你的视频（`bg.mp4`）放进文件夹，窗口背景就是动的
- **玻璃反光卡片**：图标是带高光的玻璃球质感，卡片是磨砂玻璃 + 反光
- 软件名和图标**居中显示**在窗口正上方
- 把常用入口做成卡片，**单击即开**（可以精确到某个商铺 / 商品页）
- **📋 存剪贴板链接**：在浏览器里复制商铺网址，点一下就存成卡片 —— 以后一键直达
- **🔮 悬浮球**：开启后变成一个可拖动的小球浮在桌面上，点一下弹出卡片列表，
  直接从球上打开，**不用切回主界面**
- 内置**开售倒计时**，到点弹窗 + 响铃 + 窗口置顶，还给你一个「立即前往」按钮
- 卡片可自由添加 / 编辑 / 删除

---

## 一、怎么运行

双击 **`莫印泯.exe`** 即可。

> 想放在桌面：右键 `莫印泯.exe` → 发送到 → 桌面快捷方式。

---

## 二、换成你的背景视频

1. 把视频文件放进**本文件夹**，命名为 **`bg.mp4`**
2. 打开软件（或点一下界面上的「🎬 视频背景」按钮）

支持的命名：`bg.mp4` / `bg.webm` / `bg.wmv` / `bg.avi` / `bg.mkv` / `后台.mp4` / `背景.mp4`。
也支持随便放一个视频文件进去（会自动认出来）。

> - 没放视频时，背景是**动态渐变光晕**（也挺好看），不会留白屏。
> - 视频**自动静音、自动循环**。
> - 视频也可以放到数据目录（`%APPDATA%\莫印泯\`）。
> - 点界面上的「🎬 视频背景」可以**开关**视频背景。

## 三、换图标（用你自己的图片）

现在用的是 `icon.jpg`。

1. 把你的图片存到**本文件夹**，命名为 **`icon.png`**
   （也支持 `icon.jpg`、`图标.png`、`logo.png`；名字里带 `icon` 的图也会被自动认出来）
2. 双击运行 **`一键构建.cmd`**
3. 它会把图片自动转成多尺寸 `.ico`（16/24/32/48/64/128/256）并重新编译
4. 新的 `莫印泯.exe` 就是你的图片做图标了（窗口里那个居中的圆形图标也是它）

> ⚠️ **不要直接双击 `build.ps1`** —— Windows 默认会用记事本打开它（`.ps1` 的默认程序就是文本编辑器），
> 你看到的是一堆代码，并不会运行。请双击 **`一键构建.cmd`** 那个黑窗口按钮。

### 图标效果可以调

默认是「**放大 70% + 圆角**」（主体更清楚，小尺寸下也不糊）。想改的话打开 PowerShell：

```powershell
# 默认：放大 + 圆角
.\build.ps1

# 整张图居中裁方、不要圆角
.\build.ps1 -Zoom 1.0 -Round $false

# 再放大一点（0.5 = 只取中间一半）
.\build.ps1 -Zoom 0.5
```

| 参数 | 说明 |
|---|---|
| `-Zoom` | 裁剪缩放，范围 0.1 ~ 1.0。越小画面越"放大"，主体越大 |
| `-Round` | `$true`（默认）带圆角 / `$false` 方角 |

> 小提示：用**正方形、背景干净、主体居中**的图效果最好。竖版插画建议用 `-Zoom 0.6 ~ 0.7`。

## 四、基本用法

| 操作 | 说明 |
|---|---|
| **左键单击卡片** | 打开对应的网页 / App / 程序 |
| **右键单击卡片** | 只弹菜单，不会打开（菜单：打开 / 打开备用链接 / 编辑 / 删除） |
| **＋ 添加** | 手动新增一个入口 |
| **📋 存剪贴板链接** | 把剪贴板里的网址直接存成卡片（见下面第五节，**强烈推荐**） |
| **📂 数据目录** | 打开数据文件夹（方便备份） |
| **🎬 视频背景** | 开 / 关视频背景 |
| **🔮 悬浮球** | 开 / 关桌面悬浮球 |
| **拖动顶部空白处** | 移动窗口；拖边框可以缩放 |

### 链接一栏可以填三种东西

| 类型 | 例子 |
|---|---|
| 网址 | `https://www.damai.cn` |
| **具体商铺 / 商品页** | `https://shop12345678.taobao.com` |
| App 协议 | `taobao://`、`openapp.jdmobile://`（**该 App 已安装且有注册协议时**才能拉起） |
| 本机程序 | `C:\Program Files\xxx\xxx.exe` |

> **「备用链接」**：主链接打不开时自动改用它。比如主链接填 App 协议，备用填官网网页。

## 五、一键直达某个商铺（重点）

软件本身**可以**精确跳转到某个商铺 / 商品页 —— 只要那个卡片的链接填的是那个商铺的网址就行。

最省事的做法：

1. 浏览器里打开你要的那个商铺 / 商品页
2. 按 `Ctrl + L` 全选地址栏，`Ctrl + C` 复制
3. 回到莫印泯，点 **「📋 存剪贴板链接」**
4. 卡片就存好了（名字自动取网址里的域名，右键卡片可以改名）
5. 以后**点一下卡片就直达那个商铺**

配合**悬浮球**更好用：不用切回主界面，点球 → 弹出的列表里

- 上面就是 **「＋ 存剪贴板链接」** 按钮
- 下面就是所有卡片，点一下直接打开

> **关于「录制我的操作、之后再回放」**：这个功能没有做，也不会做 —— 它就是「连点器 / 宏录制」，
> 可以拿去做秒杀、抢购、刷单，几乎所有平台都禁止；而且全局键鼠钩子在杀毒软件眼里和键盘记录器没区别，会被拦截。
> 上面这套「复制链接 → 存成卡片 → 一点直达」能拿到同样的效果，而且是干净、不会被封的做法。

## 六、悬浮球

点 **「🔮 悬浮球」** 开启后，桌面右下角会出现一个小球：

| 操作 | 效果 |
|---|---|
| **单击小球** | 弹出快捷列表（可直接打开卡片、可存剪贴板链接） |
| **按住拖动** | 把小球拖到任意位置 |
| **右键小球** | 菜单：打开主界面 / 隐藏悬浮球 / 退出 |

球的位置和开关状态会被记住，下次打开软件自动恢复。

想让开机就只出现小球（不弹主窗口）：

```powershell
莫印泯.exe --ball
```

把它放进「启动」文件夹或做个快捷方式即可。

## 七、开售倒计时

1. 在「开售时间」框里填时间（格式 `2026-10-17 20:00:00`），或点快捷按钮 `+1分 / +5分 / +10分 / 今晚20:00`
2. 「到点前往」选好到点要跳转的目标（也可以选「不跳转，只提醒」）
3. 点 **开始**

到点时会：
- 🔊 响铃（持续响，直到你点掉）
- 🪟 弹出**置顶**提醒窗，并把主窗口拉到最前
- 🚀 提供「立即前往」按钮 —— 点一下直接打开目标

> ⚠️ 这是「提醒你手动去点」，不是自动抢。跳转动作需要你点一下。

## 八、命令行参数（做快捷方式 / 计划任务用）

```powershell
# 30 秒后提醒
莫印泯.exe --in 30

# 指定时刻提醒
莫印泯.exe --at "2026-10-17 20:00:00"

# 指定到点后前往的目标
莫印泯.exe --in 600 --target 大麦网

# 直接存一条卡片（不用打开界面手动加）
莫印泯.exe --add "https://shop12345678.taobao.com" --name "我常买的那家店"

# 把剪贴板里的网址存成卡片（可以先复制好再运行）
莫印泯.exe --add clip

# 只启动悬浮球（不显示主窗口）
莫印泯.exe --ball

# 启动并直接弹出悬浮球的快捷列表
莫印泯.exe --popup
```

做一个桌面快捷方式，目标填：

```
"D:\...\莫印泯\莫印泯.exe" --in 600 --target 大麦网
```

再用 **任务计划程序** 定时启动，就能做到「到点自动叫我」。

## 九、数据存在哪

```
C:\Users\<你的用户名>\AppData\Roaming\莫印泯\links.json       ← 卡片
C:\Users\<你的用户名>\AppData\Roaming\莫印泯\settings.json    ← 开关状态（视频 / 悬浮球）
C:\Users\<你的用户名>\AppData\Roaming\莫印泯\app.ico          ← 图标副本
```

- 删掉 `links.json` = 恢复成默认的 12 个入口
- 换电脑：把这两个 `.json` 复制过去即可
- 点软件里的「数据目录」按钮可以直接打开它
- 这两个文件都是 **UTF-8（带 BOM）**，用记事本直接打开也不会乱码

## 十、自己重新编译

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

界面用的是 **WPF**（.NET Framework 自带，Win10/11 都有），编译器是 Windows 自带的 C# 编译器，
**不需要安装 Visual Studio / .NET SDK**。

文件说明：

| 文件 | 作用 |
|---|---|
| `莫印泯.exe` | 程序本体，双击即可运行 |
| `一键构建.cmd` | **双击这个**来重新构建 / 换图标 |
| `莫印泯.cs` | 全部源码（C# + WPF，纯代码构建界面） |
| `build.ps1` | 构建脚本（图片→图标→编译 exe），由 `一键构建.cmd` 调用 |
| `app.ico` | 自动生成的图标（多尺寸） |
| `app.manifest` | 高 DPI / 系统兼容声明 |
| `icon.jpg` | 图标源图 |
| `旧版备份\` | 上一版（WinForms）的源码和 exe，留个底 |

> `莫印泯.cs` 里含中文，**必须保存为「UTF-8 带 BOM」**，否则编译器会乱码报错。
> 编译时已经带上 `/codepage:65001`，正常情况下不会出问题。

## 十一、常见问题

**Q：背景视频没生效？**
A：确认文件名是 `bg.mp4` 并且和 `莫印泯.exe` 在**同一个文件夹**。然后点一下界面上的「🎬 视频背景」按钮。
如果按钮显示「无视频」就是没找到。另外视频要能被 Windows 自带播放器播放（`.mp4` / H.264 最稳）。

**Q：视频背景让画面有点糊 / 字看不清？**
A：程序在视频上盖了一层自动压暗 + 暗角，一般够用。建议用**偏暗、运动缓慢**的视频当背景。

**Q：悬浮球不见了？**
A：主界面点一下「🔮 悬浮球」就能开关。如果主窗口也被收起来了，用任务栏图标把窗口拉出来。

**Q：双击 `build.ps1` 后打开的是记事本？**
A：这是正常的 —— `.ps1` 的默认程序就是文本编辑器。请改双击 **`一键构建.cmd`**。

**Q：提示"无法加载文件，因为在此系统上禁止运行脚本"？**
A：`一键构建.cmd` 已经带了 `-ExecutionPolicy Bypass`，用它就不会有这个报错。

**Q：右键卡片结果也跳转了？**
A：老版本（WinForms 版）的 bug，新版（WPF）已经不会了。

**Q：点了卡片报"打不开"？**
A：按顺序检查：① App 协议（`taobao://` 这类）需要该 App 已安装并注册了协议；② 本机程序路径要写完整；
③ 给这个卡片填一个「备用链接」（比如官网网页），主链接失败时会自动改用它。

**Q：程序闪退 / 出错？**
A：会生成错误日志，发给我即可：`C:\Users\<你>\AppData\Local\Temp\莫印泯-错误日志.txt`

**Q：`links.json` 删了会怎样？**
A：下次启动自动恢复成默认的 12 个入口。

**Q：能加上"录制我的点击然后自动回放"吗？**
A：不能。那就是连点器 / 宏录制，可以用来秒杀抢购、刷单，平台明令禁止，
而且全局键鼠钩子会被杀毒软件当成键盘记录器拦掉。请用第五节的「复制链接 → 存成卡片」代替。

## 十二、说明

- 本程序只做**「打开链接」和「到点提醒」**，不修改任何平台的数据，不绕过任何风控。
- 不监听键盘、不记录你的操作、不自动点击、不模拟输入。
- 能不能抢到，取决于平台规则、你的网络和手速 —— 这个工具帮你的是**别错过时间、少找几下链接**。
- App 协议（`taobao://` 这类）能否拉起，取决于该 App 是否安装并在系统里注册了协议；失败时会自动尝试「备用链接」。
