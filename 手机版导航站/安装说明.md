## 二、装到手机上（三选一）

### 方式 A：电脑开个小服务，手机扫一下就能用  ★★★★★ 最推荐

这是**唯一能让数据存下来、还能「添加到主屏幕」当 App 用**的方式。

1. 把这**整个文件夹**放在电脑上（现在就在 `D:\新建文件夹`）。
2. 双击 **`一键开服.cmd`**，会弹出一个黑窗口，上面写着一行网址，类似：
   ```
   http://192.168.10.102:8898/
   ```
3. **手机连上同一个 WiFi**（要跟电脑同一个路由器），用手机浏览器打开那个网址。
4. 打开后：浏览器菜单 → **添加到主屏幕**。
   - 安卓 Chrome：右上角 ⋮ → 添加到主屏幕
   - iPhone Safari：底部分享 ⬆ → 添加到主屏幕
5. 以后点桌面上的「莫印泯」图标就能直接用，跟 App 一样。

> 用完把黑窗口关掉就是停止服务。电脑关机 / 关窗口后，手机上就打不开了。

### 方式 B：直接把文件夹拷到手机里

1. 用数据线把整个 `新建文件夹` 拷到手机的存储里（比如 `手机存储/莫印泯/`）。
2. 手机文件管理器里找到 `index.html` → 用**浏览器**打开。

> ⚠️ 这样打开的缺点：部分浏览器不允许网页保存数据，**你添加的入口可能重启就没了**（程序会弹提示告诉你）。
> 想稳定保存，用方式 A，或者方式 C。

### 方式 C：装真正的安装包（apk）  ★★★★★ 最省事

有两个版本，**程序完全一样，区别只在于有没有把视频背进去**：

| | 完整版 `莫印泯.apk` | 轻量版 `莫印泯-轻量版.apk` |
|---|---|---|
| 体积 | 约 **1.14 GB** | 约 **4 MB** |
| 内置图片 | 4 张 | 4 张 |
| 内置视频 | **4 个全背进去了** | 没有（自己点「▶ 视频 → 从相册/文件选」挑） |
| 发给朋友 | 得用数据线 / 网盘 | **微信直接发就行** |
| 安装耗时 | 好几分钟 | 几秒钟 |
| 装完不用联网 | ✅ | ✅ |

两个版本可以**同时装在一台手机上**（包名不一样，桌面图标分别是「莫印泯」和「莫印泯 轻量版」），互不影响、数据也各存各的。

**安装步骤**

1. 把 apk 弄到手机上（见下面「怎么发给朋友」）。
2. 手机上点这个 apk → 如果弹提示，允许「安装未知应用 / 来自此来源的应用」→ 安装。
   - ⚠️ **完整版**安装要好几分钟（1.1 GB 要解包），别中途退出；手机需要 **2.5 GB 以上空闲空间**（装的时候会临时多占一份）。
   - 轻量版几秒就装完，几百 MB 空间就够。
3. 桌面上出现图标，点开就能用。

**装 apk 和用浏览器的区别**

| | 浏览器版 | 装 apk |
|---|---|---|
| 电脑要不要开着 | 方式 A 要 | **不要** |
| 数据会不会丢 | 清缓存就没了 | **不会丢** |
| 唤起淘宝/京东/大麦等 App | 可以 | 可以，而且更稳 |
| 从相册选的视频 | 只当场有效 | **保存下来，下次还在** |
| 内置视频 | 有 | 完整版有 / 轻量版没有 |

> 想换背景：长按「🖼 选图」/「▶ 视频」按钮 → 从相册挑一个，apk 版会存下来。
> 想把内置的 4 个视频整个换掉，需要重新打包（跟我说）。

### 怎么发给朋友

| 办法 | 适合哪个版本 | 说明 |
|---|---|---|
| **微信 / QQ 发文件** | 轻量版 | 微信传大文件限制很严（一般 100 MB 上下），1.1 GB 根本发不过去；4 MB 的轻量版秒发 |
| **数据线拷贝** | 完整版 | 最稳：手机连电脑，把 apk 拖进手机存储 |
| **网盘分享链接** | 完整版 | 阿里云盘 / 夸克网盘快一些；百度网盘限速很慢 |
| **U 盘 + OTG** | 完整版 | 拷到 U 盘，插手机上用文件管理器打开 |

> 朋友装的时候同样会看到「未知来源」提示，让他点「允许」就行。
> 图省事的话：直接发**轻量版**，微信就能发过去。

## 三、怎么用

### 主界面按钮（上面那一排，可以左右滑）

| 按钮 | 点一下 | **长按 2 秒 = 右键** |
|---|---|---|
| ＋ 添加 | 打开编辑面板，加一个新入口 | — |
| 📋 剪贴板 | 把剪贴板里的链接存成卡片 | — |
| 🔁 自动切换 | 开 / 关背景图自动切换 | 弹菜单：立刻换下一张 / 选图 / 改间隔 |
| 🖼 选图 | 打开图片列表挑一张 | 再选一张 / 回到内置图 / 图片列表 |
| ▶ 视频 | 开 / 关视频背景 | 弹菜单：选择视频 / 不用视频 |
| ☰（右上） | 设置面板 | — |
| 左上角图标 | — | 弹菜单：设置 / 换背景 / 存剪贴板链接 |

### 卡片

- **轻点** = 打开链接。
  如果是 App 协议（`taobao://` 这种），会先试着唤起 App；App 没装就自动跳「备用链接」。
- **长按 2 秒** = 右键菜单：打开 / 复制链接 / 编辑 / 移到最前 / 删除。
  长按的时候指尖会出现一个**进度圈**，转满一圈才弹菜单，所以不会误触。

### 背景

- **图片**：默认每 **60 秒**自动换一张（可在设置里改成 10 / 20 / 30 / 60 / 120 / 300 秒）。
  切换是淡入淡出，很柔和。
- **自己挑了一张图之后，自动切换会停下来**（按你说的）。
  想恢复：设置 → 图片自动切换 打开，或者选图面板里的「恢复自动切换」。
- **视频**：默认是关的。点「▶ 视频」打开，默认播体积最小的 `1-miku.mp4`。
  想换：长按「▶ 视频」→ 选择视频。

### 设置面板里有什么

- 图片自动切换 开/关
- 切换间隔（点一下循环切换）
- 视频背景 开/关
- 选择视频
- **长按判定时长**（0.5 / 0.8 / 1 / 2 / 3 秒）← 默认 2 秒，嫌慢可以调成 0.8 秒
- 省电模式（关掉毛玻璃，老手机更流畅）
- 卡片也用液态玻璃（更漂亮，但更吃性能）
- 导出我的入口 / 导入入口 / 恢复默认 12 个入口

## 四、往里面加图片和视频

1. 把图片丢进 `图片\` 文件夹，视频丢进 `视频\` 文件夹。
   - 图片：`.jpg .jpeg .png .gif .webp .bmp` 都行
   - 视频：`.mp4 .webm .mov .m4v .mkv` 都行
   - 文件名可以随便起，但**建议用英文或数字**，别带 `#` `[` `]` 这些符号（地址里会出问题）。
   - 文件名的开头数字会被去掉当标题，比如 `5-我的背景.mp4` → 标题「我的背景」。
2. 双击 **`重新生成素材清单.cmd`**（不开服务也能跑）。
3. 回到手机刷新页面，新素材就出现在选择列表里了。

> 手机上临时从相册选的图片会压缩后存下来，重开也在；
> 临时选的视频只在这一次打开有效（视频太大存不进浏览器）——**装了 `莫印泯.apk` 的话，选的视频也会被存下来，下次还在**。
>
> ⚠️ 上面这套只对**浏览器版**和**电脑开服务**有效。apk 里的图片视频是**打包进去**的，
> 往文件夹里加了新素材，apk 不会跟着变——想让 apk 也带上新素材，跟我说，我重新给你打一个包。

## 五、小提示

- **卡片数据存在哪**：手机浏览器的本地存储里，不上传任何服务器。换手机 / 清浏览器数据会没，建议用设置里的「导出我的入口」备份一下（会复制成一段文字，可以发到微信存着）。
- **性能**：背景播视频 + 一堆毛玻璃会比较吃 GPU。卡的话：设置 → 打开「省电模式」，或者把视频关掉用图片背景。
- **那个 4K 视频**：`4-kuroha-4k.mp4` 是 4K 440MB，很多手机硬解不了会卡。建议用 `1-miku.mp4`（22MB）当背景。
- **液态玻璃怎么实现的**：不是简单的模糊，是用 SVG 滤镜做的——
  `feTurbulence` 生成有机噪声 → `feDisplacementMap` 把高光边框「掰弯」做出边缘折射 →
  再把图层拆成红 / 绿 / 蓝三个通道分别用不同强度位移，最后 `feBlend screen` 叠回去，
  得到边缘的彩色色差（chromatic aberration）。每个面板的高光还会缓慢流动，就是那个「液态」感。
