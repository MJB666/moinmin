# 这个文件夹是空的（故意的）

`media.js` 里原本有 4 个视频，**仓库里没有包含它们**，原因是：

- 体积太大（4 个加起来约 1.1 GB）
- 同时涉及版权问题（详见仓库根目录的 [免责声明](../../免责声明.md)）

所以这里现在是空的。想让视频背景能用，把你自己**有权使用**的视频放进这个文件夹，然后：

**如果是用浏览器 / 开服务的方式**
1. 双击上一层的 `重新生成素材清单.cmd`
2. 手机刷新页面，视频就会出现在「▶ 视频 → 选择视频」的列表里

**如果是自己重新打包 apk**
视频文件会一起被打进去，见上一层的 `安装说明.md`。

> 文件名建议用英文或数字，别带 `#` `[` `]` 这些符号。
> 开头的数字会被去掉当标题，比如 `5-我的视频.mp4` → 标题「我的视频」。
>
> 另外提醒：4K 视频（比如 440 MB 那种）很多手机硬解不了，当背景会卡，
> 建议用 20 MB 左右的小视频。
